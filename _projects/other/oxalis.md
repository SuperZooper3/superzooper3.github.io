Oxalis was my team's submission for a Moonshot Hackathon where we had to solve a major world issue using innovative technology. The problem we tackled was the donor based blood supply, instead proposing a technology that could allow blood substitutes to be manufactured in bulk.

![Screenshots from the project](/assets/img/projects/other/oxalis.png)

I developed the main deliverable which was the [website](https://oxalismed.com/) using bootstrap, as well as editing the video and making the presentation deck. All that content can be found [here](https://oxalismed.com/content.html).

![Screenshots of the content](/assets/img/projects/other/oxalisContent.png)

I'm super glad with how this project came out! I think we had a really innovative idea and I'm proud of how clean the website looks.

You can read more about the project as well as find all it's associated content on our website [oxalismed.com](https://oxalismed.com/).
