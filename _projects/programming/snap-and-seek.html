Hide. Seek. Snap. Find them all.

Snap & Seek is a whimsical real-world mobile game I made for TreeHacks. It turns an outdoor game zone into a mix of hide and seek, scavenger hunt, geocaching, and Jet Lag-style running around with friends.

Players hide an item or landmark in the play area, snap a photo as proof, then race to find everyone else's hidden spots. To narrow the search, teams can use clues and powerups like Radar, Thermometer, and Photo/Landmark hints.

The game has a mobile-first map interface, game-zone setup, invite links, and live player/game state so it can be played outside on a campus, park, or anywhere friends can safely explore. It was built with Next.js, Vercel, Supabase, and Google Maps.

Play it at snap-and-seek-game.vercel.app, see it on Devpost, watch the trailer on YouTube, and find the source code on GitHub.
