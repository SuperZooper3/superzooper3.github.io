Voiceflow GameFlow is a Unity game that integrates Voiceflow, an AI-powered conversational interface, to create an immersive experience. The game features an LLM-driven NPC that can engage in organic conversations, access a knowledge base of lore, and interact with the game world by giving or receiving items and changing scenes. This allows for a unique blend of narrative and gameplay, where the player's choices and interactions shape the story. Voiceflow GameFlow demonstrates the potential of combining cutting-edge language models with traditional game development to create novel interactive experiences.

You can find the source code on GitHub and watch the video on YouTube.
