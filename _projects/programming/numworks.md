This is a collection of four smaller projects making small games for the [Numworks Calculator](https://www.numworks.com/) that I had in high school so I could play them if I was bored.

I made three games (Tetris, Minesweeper and Dance) as well as a fun way to encode and store images (I deigned my own silly image compression system because we don't easily have access to the calculator's storage).

![Photo](/assets/img/projects/numworks_photo.jpg)

These games all run on the stock calculator using the python app without any jailbreaking.

![Tetris](/assets/img/projects/tetris.png)

*You can find this collection of games and tools as well as a more thorough documentation and showcase on [GitHub](https://github.com/SuperZooper3/Numworks-Games).*
